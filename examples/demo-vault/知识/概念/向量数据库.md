# 定义
[[向量数据库]] 是专门处理 embedding 存储、近邻检索和元数据过滤的系统。在 LLM 应用里，它通常承担召回层的基础设施角色。

# 选型关注点
- 检索延迟、索引构建速度、过滤表达能力。
- 多租户与权限隔离，尤其对 [[数据不出境]] 很关键。
- 与 [[RAG（检索增强生成）]]、[[智能文档平台]] 的集成成本。
