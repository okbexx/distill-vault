# 约束说明
涉及客户数据、内部文档和业务指标的知识处理流程必须优先在境内部署环境中完成，避免敏感数据外流。

# 影响范围
- [[智能文档平台]] 的存储与索引方案必须支持私有部署。
- [[AI客服助手]] 的检索、日志和审核链路都要受此约束。
- [[推荐系统优化]] 的实验数据同步方式也需谨慎设计。
