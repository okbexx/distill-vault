# 项目目标
打造一套供研发、运维和产品共同使用的内部工具链，让脚本、知识查询、巡检和分析动作通过统一入口完成。

# 核心思路
- 以 [[Agent]] 作为统一交互层。
- 通过 [[RAG（检索增强生成）]] 读取知识库和运维文档。
- 通过 [[知识图谱]] 管理工具、服务、负责人和操作流程之间的关系。
