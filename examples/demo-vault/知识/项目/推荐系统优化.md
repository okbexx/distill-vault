# 项目目标
对现有推荐系统做架构改造，把召回、排序、特征计算和实验分析拆成可独立演进的服务。

# 当前思路
- 以 [[微服务架构]] 作为主要架构原则。
- 用统一日志和链路追踪减少跨服务排障难度。
- 未来可能引入 [[Agent]] 帮助运营同学自动分析实验异常，但目前仍处于探索阶段。
