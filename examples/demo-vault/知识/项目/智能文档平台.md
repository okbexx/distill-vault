# 项目目标
把分散在团队网盘、Confluence 和本地笔记中的知识统一到一个可搜索、可分析、可追踪的智能文档平台。

# 核心设计
- 通过 [[知识图谱]] 把文档、术语、来源和实体连接起来。
- 通过 [[向量数据库]] 承担语义召回能力。
- 通过 [[RAG（检索增强生成）]] 让用户直接用自然语言向知识库提问。

# 关键决策
- 采用 [[选择Milvus作为向量数据库]] 来满足扩展性要求。
- 采用 [[知识库采用Obsidian格式]] 以兼顾本地优先、易编辑和链接友好。
